# 렌트로그 시연 영상 시나리오 (Pleos Connect 에뮬레이터 + Virtual Console)

데모 패널(제목 길게 누르기)은 **사용하지 않습니다.** 차량 신호는 Pleos Virtual Console로, 나머지는 화면 터치로 진행합니다.

## 0. 촬영 전 준비 (매 테이크마다)
1. `Pleos_Connect_v2.1.0` AVD를 **Cold Boot**로 실행합니다. (Device Manager → ▼ → Cold Boot Now, RAM 4GB 이상)
   - 콘솔의 주행거리는 **줄일 수 없습니다**(`traveled_distance_must_not_decrease`). 테이크를 다시 찍으려면 반드시 콜드 부팅해서 0으로 되돌립니다.
   - 비행기 모드를 켠 뒤에는 에뮬레이터 네트워크가 끊겨 콘솔이 먹통이 됩니다. 반드시 콜드 부팅으로 복구합니다.
2. 터미널: `adb forward tcp:8088 tcp:8088`
3. **브라우저에서 `http://127.0.0.1:8088/` 를 열어 두고 닫지 않습니다.** (페이지가 열려 있어야 콘솔이 활성화됩니다.)
4. 콘솔 초기값 설정 (브라우저 카드 또는 아래 curl):
   - Odometer = **12340** km, Battery SOC = **80** %, Gear = **P**, Telltales(TPMS, ABS) = **Off**, 문 모두 닫힘
   - 콘솔 Body 패널에서 FRUNK/TRUNK와 문·창문이 모두 Closed인지 확인 (열려 있으면 출발 전 검수에서 출발이 막힙니다)
5. 앱 설치/실행: Android Studio Run ▶ 또는 `adb install -r app/build/outputs/apk/debug/app-debug.apk`
   - 앱을 다시 시작하면 앱 내부 가짜 서버(FakeBackend)가 초기화됩니다. 인증번호는 `1234`.

## 1. 장면별 진행

| # | 장면 | 조작 | 화면 결과 |
|---|---|---|---|
| 1 | F-01 대여 시작·본인 확인 | 키패드로 틀린 번호 4자리 → 정답 `1234` | "번호가 달라요 (남은 횟수 4회)" → 정답이면 F-02 |
| 2 | F-02 출발 전 검수 | (콘솔 값이 자동 반영) | 주행거리 12,340 km, 연료(=배터리) 80 %, 경고등 0개, 문 모두 닫힘 → **확인, 출발하기** |
| 2-1 | (선택) 트렁크 열림 시연 | 콘솔에서 **TRUNK = Open** (F-02 화면에서) | F-02 '문 · 창문 / 열림 있음 · 트렁크 열림 / 주의', 하단 "트렁크가 열려 있어요…", **확인, 출발하기 비활성** → 콘솔에서 **TRUNK = Close** → 1~2초 뒤 '모두 닫힘 / 정상', 출발 가능 |

| 8 | F-06 반납 전 안내 | 콘솔 ABS = Off, Odometer **12612**, Battery SOC **62** | 출발 **약 1분 뒤** 운행 화면에서 자동 표시(반납까지 2시간). 272 km → 67,760원 |

| 10 | F-07 반납 검수 | 콘솔 **Gear = P** (또는 "반납 장소에 도착했어요") | 인수/반납 비교표 + 정산 미리보기 → **반납 확정 · 명세서 받기** |
| 11 | F-11 반납 완료 | — | 272 km, 67,760원, 기록 검증 코드 → **명세서 미리 보기** → 닫기 → F-01 |
| 12 | F-08 확인 잠김 | (앱 재시작 후) 틀린 번호 5회 | "본인 확인이 잠겼어요" |
| 13 | F-08 연결 끊김 (마지막에!) | 에뮬레이터 **비행기 모드 ON** → '확인, 출발하기' 등 서버 요청 동작 | 5초 후 "연결이 끊겼어요" → 비행기 모드 OFF → **다시 시도** → 중단된 동작이 이어서 실행됨 |

주의
- F-06은 **운행 화면(F-03)에 있을 때만** 뜹니다. F-10/F-05 화면 중에는 뜨지 않으니 확인 후 운행 화면으로 돌아오세요.
- 13번(연결 끊김)은 영상의 **맨 마지막**에 넣으세요. 이후에는 콜드 부팅이 필요합니다.

## 2. 콘솔을 명령줄로 조작하는 방법 (브라우저 카드와 동일, 브라우저 페이지를 열어 둔 상태에서)
```
C=http://127.0.0.1:8088/vehicle
curl -X PUT "$C/odometer?traveled_distance_km=12340"
curl -X PUT "$C/ev-battery?field=soc&value=80"
curl -X PUT "$C/gear?gear=Park"            # Drive
curl -X PUT "$C/telltales/simulator?color=Red&state=On&type=TPMS"   # state=Off, type=ABS
curl -X PUT "$C/body?door_fl=true"          # 문 열림 (false=닫힘). door_fr / door_rl / door_rr
curl -X PUT "$C/body?trunk=true"            # 트렁크 열림 (false=닫힘)
curl -X PUT "$C/body?frunk=true"            # 프렁크 열림 (false=닫힘)
curl -X PUT "$C/body?window_fl=50"          # 창문 열림 0~100 % (0=닫힘). window_fr / window_rl / window_rr
# 모두 닫기 (촬영 전 준비)
curl -X PUT "$C/body?trunk=false&frunk=false&door_fl=false&door_fr=false&door_rl=false&door_rr=false&window_fl=0&window_fr=0&window_rl=0&window_rr=0"
```
비행기 모드: `adb shell cmd connectivity airplane-mode enable|disable`

## 3. 알려진 한계
- 콘솔에는 연료/속도 조절이 없습니다(전기차). 화면의 "연료"는 배터리 SOC 값을 표시합니다.
- 브레이크 전용 telltale이 없어 **ABS**를 긴급(브레이크) 경고로 사용합니다.
- 앱에 `PRIVATE_CAR_SAFETY` 권한을 선언했습니다(telltale 읽기에 필요). 스토어 제출 시 Pleos App Market 사전 승인이 필요합니다.
- 업체 전화번호(02-1234-5678), 정비소/반납장소 이름은 임시값입니다.

## 4. scripts 사용법 (자동 테스트 / 자동 시연)
`scripts/` 의 Python 3 스크립트(표준 라이브러리만 사용)는 adb + uiautomator 로 앱을, HTTP 로 Virtual Console 을 직접 조작합니다.

사전 조건
- 에뮬레이터 **Cold Boot** 직후 상태 권장(주행거리 0 km). 주행거리는 **줄일 수 없으므로** 스크립트는 현재 값을 인수 기준으로 삼아 +272 km 만 올립니다(요금 67,760원 동일). 반복 실행하면 주행거리가 계속 누적됩니다.
- `adb forward tcp:8088 tcp:8088` (콘솔 접근), 디버그 APK 설치(`adb install -r app/build/outputs/apk/debug/app-debug.apk`).
- **브라우저 불필요**: 스크립트가 콘솔 하트비트(`POST /browser/session`, 1초 간격)를 대신 보냅니다. 브라우저 탭을 열어 두면 클라이언트가 둘이 되지만 문제는 없습니다.
- 비행기 모드/네트워크 변경 금지(콘솔이 먹통이 되며 콜드 부팅이 필요). 데모 패널(제목 길게 누르기)은 사용하지 않습니다.

명령
```
python3 scripts/e2e_test.py [--only lock,blockers,flow,tire] [--out DIR]   # 통합 테스트, 실패 시 종료코드 1
python3 scripts/demo_autoplay.py [--pause 4] [--skip-lock] [--no-problem-scene] [--shots]   # 시연 자동 재생
```
- `e2e_test.py`: 잠김 / F-02 차단 항목별(트렁크·프렁크·창문·문·타이어·TPMS·ABS·에어백·LED 헤드램프·AFS·배터리 15 %, 복합 '외 N건') / 정상 흐름 F-01~F-11·명세서 / 주행 중 공기압 하강. 단계별 PASS/FAIL 과 스크린샷(`scripts/out/<시각>/`)을 남깁니다. 약 6~7분.
- `demo_autoplay.py`: 장면마다 한 줄(`[장면 3/19] ...`)을 출력하고 `--pause` 초만큼 정지합니다(영상 녹화용, 기본 4초). `--skip-lock` 은 마지막 오답 5회 잠김 장면 생략, `--no-problem-scene` 은 F-02 문제 연출 생략. 종료 시 콘솔을 중립 상태(기어 P, 경고등 Off, 문 닫힘, SOC 80)로 되돌립니다. F-06 은 출발 약 60초 뒤에 떠야 하므로 전체 약 3분 이상 걸립니다.
- 알려진 에뮬레이터 한계: Pleos Connect 에뮬레이터의 CarService 가 `TIRE_PRESSURE` 속성을 노출하지 않아 앱이 타이어 kPa 를 읽지 못합니다(콘솔 값은 바뀌지만 앱 화면은 '경고 없음 · 공기압 경고등 꺼짐'). 타이어 kPa 항목은 SKIP 으로 보고되며, TPMS 경고등(telltale) 경로로 같은 차단/F-04 흐름을 검증합니다.
- `./gradlew connectedDebugAndroidTest` 는 `--offline` 이 아닌 온라인 상태에서 실행해야 합니다(UTP 의존성 다운로드). 실행 후 앱이 에뮬레이터에서 제거되므로 `adb install -r` 로 다시 설치하세요.
