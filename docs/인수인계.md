# 인수인계

처음 합류한 팀원이 **무엇을 어디서 보고 어떻게 이어 개발할지** 정리한 문서입니다. 실행·테스트 방법은 [README](../README.md), 시연 순서는 [시연_시나리오](시연_시나리오.md)를 먼저 보세요.

## 1. 읽는 순서
1. README (실행, SDK, 에뮬레이터, 콘솔)
2. 이 문서 (구조와 결정 사항)
3. `ui/AppState.kt` (화면 목록 `Screen`과 상태 `UiState`) → `ui/AppViewModel.kt` (모든 흐름)
4. `data/vehicle/PleosVehicleDataSource.kt` (SDK 연동)
5. 테스트 `AppViewModelFlowTest.kt` (흐름이 코드로 정리되어 있어 명세서처럼 읽힙니다)

## 2. 구조

```
RentLogApp (수동 DI) ─ AppDeps ─┬─ FakeBackend        가짜 서버 (예약·인증·검수·이벤트·정산)
                                ├─ VehicleDataSource  Pleos SDK 래퍼 (PleosVehicleDataSource) / 시뮬레이터
                                ├─ Speaker            TTS 음성 (VoiceGuide)
                                ├─ NaviRouter         내비 호출 (NaviLauncher)
                                └─ NetworkStatus      연결 상태
AppViewModel ── StateFlow<UiState> ── Compose 화면(ui/screens)
```

- DI 프레임워크 없이 `RentLogApp.deps`에서 직접 만들고 `viewModelFactory`로 주입합니다. 테스트에서는 가짜 구현을 `AppDeps`에 넣습니다.
- **단일 ViewModel + 단일 상태**입니다. `UiState.screen`(`Screen` sealed interface) 값이 곧 현재 화면이고, 화면 컴포저블은 상태를 그리고 이벤트만 올립니다.
- 시간은 `AppDeps.clock`, 각종 주기는 `AppConfig`로 주입해서 테스트에서 줄일 수 있습니다.

## 4. 핵심 설계 결정 (바꾸기 전에 이유를 읽어 주세요)

| 결정 | 이유 |
|---|---|
| `PleosVehicleDataSource`는 SDK 접근을 모두 보호하고, 서비스가 없으면 `SimulatedVehicleDataSource`로 **조용히 폴백** | 일반 에뮬레이터·폰에서도 앱이 죽지 않게. `isSimulated`로 현재 모드를 알 수 있음 |
| 경고등(telltale)은 **구독이 아니라 1초 폴링** | telltale 구독은 권한이 필요한 API라 폴링으로 대체 |
| 브레이크 전용 경고등이 없어 **ABS를 긴급(BRAKE) 경고**로 사용 | Virtual Console에 브레이크 telltale이 없음 |
| 경고 종류: TPMS = 주의(`CAUTION`), ABS = 긴급(`EMERGENCY`) | `VehicleMapping.kt`, 테스트 `VehicleMappingTest` |
| 요금 = `max(0, 주행거리 - 30) × 280원` | `FeeCalculator`. 272 km → 67,760원 |
| 출발 시 반납 예정 = 지금 + 2시간 1분, 반납 2시간 전에 F-06 표시 | 시연에서 출발 약 1분 뒤 F-06이 뜨게 하려는 값(`AppConfig.demoReturnAfterDepartureMs`) |
| 기록 검증 코드는 HMAC-SHA256 해시 체인 (`HashChain`, `FakeBackend.SECRET`) | 기록 위변조 방지 개념 시연용. **데모 키라 실서비스에서는 서버가 관리해야 함** |
| 서버 요청은 5초 타임아웃 후 F-08 "연결이 끊겼어요" → 재시도 시 중단된 동작을 이어서 실행 | `AppConfig.requestTimeoutMs` |
| 본인 확인 5회 오답 시 잠김 | `FakeBackend.verify` |
| 연료 = 배터리 SOC | 전기차 |
