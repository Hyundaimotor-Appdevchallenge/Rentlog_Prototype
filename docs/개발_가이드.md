# 개발 가이드

## 브랜치와 PR
- `main`은 보호되어 있어 **직접 푸시할 수 없습니다.** (첫 공유 커밋만 예외)
- 브랜치 이름: `feat/짧은-설명`, `fix/…`, `docs/…`, `test/…`, `chore/…`
- PR 하나에는 한 가지 목적만 담습니다. PR 템플릿의 체크리스트를 채우고, CI(빌드 + 단위 테스트)가 초록불이어야 머지합니다. 승인은 1명 이상 받습니다.

## 커밋 컨벤션 (Conventional Commits)
```
<type>(<scope>): <한 줄 요약, 마침표 없음, 50자 안팎>

<무엇을 왜 바꿨는지, 필요하면 여러 줄>
```
| type | 쓰임 |
|---|---|
| `feat` | 기능 추가 |
| `fix` | 버그 수정 |
| `refactor` | 동작 변경 없는 구조 개선 |
| `test` | 테스트 추가·수정 |
| `docs` | 문서 |
| `chore` | 빌드·설정·의존성 |
| `ci` | GitHub Actions |

- scope 예: `ui`, `vehicle`, `data`, `service`, `e2e`
- **논리 단위로 쪼개서** 커밋합니다. 한 커밋은 빌드와 테스트가 통과하는 상태여야 합니다. 리팩터링과 기능 추가를 한 커밋에 섞지 마세요.
- 요약은 한국어 또는 영어 중 팀이 정한 한 가지로 통일합니다(현재는 한국어).

## 자주 하는 작업

### 새 화면 추가
1. `ui/AppState.kt`의 `Screen`에 값을 추가하고 필요한 필드를 `UiState`에 추가
2. `ui/screens/`에 컴포저블 작성 (공통 부품은 `ui/components/`에서 재사용)
3. `AppViewModel`에 이동·이벤트 처리 추가, `MainActivity.kt`의 화면 분기 `when`에 연결
4. `AppViewModelFlowTest`에 흐름 테스트 추가, 시연 순서가 바뀌면 `docs/시연_시나리오.md`와 `scripts/`도 갱신

### 차량 신호 추가
1. `data/model/Models.kt`의 `VehicleSnapshot`(필요 시 `VehicleWarning`)에 필드 추가
2. `VehicleDataSource` 인터페이스에 시뮬레이터용 훅 추가 (기본 구현 `{}`을 두면 기존 클래스가 깨지지 않음)
3. `PleosVehicleDataSource`(실제 SDK)와 `SimulatedVehicleDataSource` 양쪽 구현. **SDK 호출은 모두 try/catch로 보호**
4. 판정 규칙은 `VehicleMapping.kt`에 두고 `VehicleMappingTest`로 검증
5. 필요한 권한이 있으면 `AndroidManifest.xml`에 추가하고 README의 권한 목록 갱신
6. SDK의 실제 속성 이름과 값은 추측하지 말고 Pleos 문서와 기존 래퍼 코드를 확인

### 의존성 추가
`gradle/libs.versions.toml`에 버전과 라이브러리를 추가하고 `app/build.gradle.kts`에서 `libs.…`로 사용합니다. 버전을 코드에 직접 쓰지 않습니다.

## PR 전 체크리스트
- [ ] `./gradlew assembleDebug testDebugUnitTest` 통과
- [ ] UI·차량·흐름을 건드렸다면 에뮬레이터(Cold Boot)에서 `python3 scripts/e2e_test.py` 통과 (관련 시나리오만 `--only`로 돌려도 됨)
- [ ] 화면이 바뀌었다면 스크린샷을 PR에 첨부
- [ ] 문서(README, docs/)를 함께 갱신
- [ ] 비밀값·개인 경로·개인 설정 파일(`local.properties`, `.idea` 개인 설정)이 없는지 확인 (공개 저장소)
- [ ] 커밋이 논리 단위로 나뉘어 있고 컨벤션을 지킴

## 코드 스타일
- Kotlin 공식 스타일(`kotlin.code.style=official`), 들여쓰기 4칸
- 상태는 `UiState`에 모으고 화면에는 로직을 넣지 않습니다.
- 시간·타임아웃은 `AppDeps.clock`, `AppConfig`로 받아 테스트에서 제어합니다.
